01 / Overview

Bringing Milk Delivery Online

Traditional milk delivery can involve manual customer records, delivery tracking, subscription management, and billing. Keeping these activities organized becomes difficult when information is spread across separate records.

Milkman explores a centralized, web-based approach to these operations. Customers can browse dairy products, add items to a cart, place orders, and manage subscriptions through the application's interface.

The project uses React for the frontend and Django for backend functionality, with API communication connecting the application layers.

02 / Functionality

Key Features

An overview of the workflows demonstrated in the application.

Customer Registration

A customer registration interface for collecting account and contact details.

Product Catalogue

Browse dairy products with product information, prices, and shopping controls.

Subscriptions

Select a product subscription, choose a delivery frequency, and specify a start date.

Cart and Billing

Review cart items, quantities, order totals, customer details, and checkout information.

Order Confirmation

Display order confirmation details and a summary of the submitted order.

Subscription History

View subscription information, including the selected product, frequency, start date, and status.
